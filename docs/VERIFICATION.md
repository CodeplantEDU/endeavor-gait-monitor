# 공개본 검증 기록

검증일: 2026-10-27. 이 문서는 GitHub 공개본 준비 과정에서 직접 실행한 검사 범위를 기록한다.

| 검사 | 결과 |
|---|---|
| `npm test` | Node 단위 검사 36개 통과 |
| `npm run test:python` | Python API·저장 검사 14개 통과 |
| `npm run build` | 공개 웹 21개 파일 생성, 서버 함수·필수 모듈 별도 구성 |
| `npm run test:browser` | 합성 CSV 업로드·정제·그래프·모의 AI·저장·새로고침 복원·모바일 폭·잘못된 CSV 초기화 통과 |
| 비밀 값 비교 | 현재 실행 환경의 API 키와 기존 운영 이용 코드가 공개 소스에 없음을 확인 |
| 공개 파일 검사 | 실행 데이터·비밀 파일·개인 절대 경로·일반적인 자격 증명 패턴 검사 통과 |
| 펌웨어 | 기준 소스의 INO·헤더와 바이트 단위 동일 |
| npm 잠금 파일 | 공개 npm 레지스트리의 고정된 개발 의존성 사용 |

이번 공개본 검사에서는 실제 OpenAI API를 호출하지 않았다. 브라우저 검사는 모의 응답이며 과금·실제 센서·실제 참여자·임상 정확도의 증거가 아니다. 새 환경에서의 모델 접근 권한·장치 드라이버·Arduino 업로드·별도 Vercel 프로젝트 배포는 각 환경에서 확인해야 한다.

## 참고용 과거 검사 스크립트

`tests/research-browser-check.cjs`는 주기·기준선 중심의 이전 화면 기대값을 포함한다. 기본 npm 검사에서는 실행하지 않으며 현재 CSV 경로는 `tests/csv-browser-check.cjs`를 사용한다. 실제 장치를 요구하는 `tests/hardware-browser-check.cjs` 역시 CI에서 실행하지 않는다.

## 공개에서 제외한 자료

`.env*` 실제 설정, 운영 이용 코드, `.vercel` 연결 정보, SQLite 기록, 측정·보고서 출력, 개인 CSV, 로컬 백업, 원본 첨부 지시서와 신청서, 개인 검사 로그는 포함하지 않았다. 기능 테스트용 CSV는 `examples/`에 합성 자료임을 명시해 별도 제공한다.
